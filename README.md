# 싸이월드 리부트 클린 뼈대

## 실행 방법

처음 한 번:

```cmd
npm run install:all
```

실행:

```cmd
npm start
```

현재 버전은 DB 없이 localStorage에 임시 저장됩니다. 나중에 Supabase로 교체하기 쉽도록 `frontend/src/services`와 `backend` 폴더를 미리 분리했습니다.

## 포함 기능

- 첫 화면
- 회원가입
- 아이디 중복체크
- 로그인
- 로그인 상태 유지
- 신규 가입 도토리 200개 지급
- 메인 페이지
- 상태 메시지 자동 연동
- 최근 활동 자동 연동
- 알림 자동 연동
- 내 미니홈피
- 일촌 목록 더미 표시
- 프로필 수정
- 모바일 버튼 텍스트 줄바꿈 방지
